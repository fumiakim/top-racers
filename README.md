# TOP RACERS — 俯瞰レース

1〜2人で遊べる、**画面スクロールなし・パースなし**の真俯瞰レースゲーム。
コース全体が常に1画面に収まる。単一 HTML + Canvas、ビルド・依存なし。

## あそびかた

`index.html` をブラウザで開くだけ。

| | アクセル / ブレーキ | ハンドル |
|---|---|---|
| 1P | `↑` / `↓` | `←` `→` |
| 2P | `W` / `S` | `A` `D` |

`P` ポーズ / `R` やり直し / `Esc` メニューへ

- 1人プレイ：CPU 3台と対戦
- 2人プレイ：対戦 ＋ CPU 2台
- 周回数は 3 / 5 / 8 から選択
- **コース外は壁**。ぶつかると弾かれて減速し、擦れば削られる

## しくみ（実装メモ）

### コース形状 — 直線＋一定半径の円弧
コースは **多角形の頂点 `[x, y, コーナー半径]`** だけで書く（`COURSES[].pts`）。
各頂点を指定半径の円弧でフィレットし、頂点間は直線でつなぐ。
スプライン補間と違い**カーブが必ず一定半径**になるので、歪んだコーナーができない。

- `fitRadii()` … 隣り合うコーナーの円弧が重なる場合、両方の半径を自動で詰める
- `buildSegs()` … 直線・円弧のセグメント列に展開
- `sampleLoop()` … 全長を等間隔（6px）に打ち直し、各点に接線・法線・**符号付き曲率**を持たせる

曲率が厳密に分かるので、CPU の「曲がりきれる速度」もオーバーヘッドなしで正確に出せる。

**コース追加**は `COURSES` に1要素足すだけ。ミニマップ・壁・チェックポイントは自動生成。
頂点は**進行方向に並べ、最後の頂点→先頭の頂点が長いストレートになるように**書くと、
そのストレートにスタート／フィニッシュラインが乗る。

設計時の目安：
- 最小コーナー半径 ≧ コース幅の 0.85 倍（内側の壁が詰まりすぎない）
- 別々の区間どうしの間隔 ≧ 50px 程度

### 壁の当たり判定
中心線からの横位置 `off`（法線方向の内積）で判定する。
`|off| > 半幅 − 車半径` になったら位置を壁の内側へ戻し、法線方向の速度を反発させ、
接線方向は当たりの強さに比例して減速させる。壁をすり抜けることはない。

低速時でもアクセルを踏んでいれば舵が効くようにしてある
（これが無いと壁に鼻から刺さったまま脱出できなくなる）。壁に直角にぶつけても約1.2秒で復帰できる。

### そのほか
- **物理**：速度ベクトル + 車体角。横方向速度をグリップ分だけ吸収（残りがドリフト感）
- **周回判定**：コースを 12 のチェックポイントに分割し、**順番に一周ぶん通過して初めて**
  1ラップ成立。スタート直後の押し合いでラインをまたいでも誤カウントしない
- **CPU**：先読み点へ向かう P 制御 ＋ コーナー内側へのライン取り。
  先の最小旋回半径 R から `PHYS.turn * R` を上限速度としてアクセルを調整する。
  `skill` で個体差、`lane` で走行ラインの癖をつけている
- **描画**：路面・路肩・赤白の縁石・タイヤバリアは起動時に一度だけオフスクリーンへ描画。
  アスファルトのざらつきは `source-atop` でノイズを路面だけに乗せている
