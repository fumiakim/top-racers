# TOP RACERS — 俯瞰レース

1〜2人で遊べる、**画面スクロールなし・パースなし**の真俯瞰レースゲーム。
コース全体が常に1画面に収まる。単一 HTML + Canvas、ビルド・依存なし。

▶ **https://fumiakim.github.io/top-racers/**

## あそびかた

`index.html` をブラウザで開くだけ。

| | アクセル / ブレーキ | ハンドル |
|---|---|---|
| 1P | `↑` / `↓` | `←` `→` |
| 2P | `W` / `S` | `A` `D` |

`P` ポーズ / `R` やり直し / `M` ミュート / `Esc` メニューへ

- 1人プレイ：CPU 3台と対戦
- 2人プレイ：対戦 ＋ CPU 2台
- 周回数は 3 / 5 / 8 から選択
- **赤白の縁石ラインを越えると減速**（路肩は滑って砂ぼこりが上がる）
- **さらに外側は壁**。ぶつかると弾かれて減速する
- ゴールした CPU はコースから退場する

## コース

| # | 名前 | 難易度 | 全長 | 路面幅 | コーナー | CPU 参考ラップ |
|---|---|---|---|---|---|---|
| 1 | ベイサイド・サーキット | ふつう | 約 2350px | 132px | 8 | 7.0〜7.4 秒 |
| 2 | マウンテン・テクニカル | むずかしい | 約 2600px | 111px | 11 | 8.0〜8.5 秒 |
| 3 | ラビリンス・サーキット | 最上級 | 約 3270px | 96px | 12 | 10.9〜11.5 秒 |

ラビリンスは 12 コーナーの半径をすべて変えてあり（78 / 95 / 100 / 105 / 110 / 130px）、
高速キンク → 深い U 字 → 鋭い V 字 → ロングストレート と性格の違うコーナーが並ぶ。
路肩を他より狭くして（12px）壁を近づけてあるため、最小半径を 78px まで詰められる
（コーナー内側の壁半径 18px、コーナリング上限は最高速の約 80%）。

## しくみ（実装メモ）

### コース形状 — 直線＋一定半径の円弧
コースは **多角形の頂点 `[x, y, コーナー半径]`** だけで書く（`COURSES[].pts`）。
各頂点を指定半径の円弧でフィレットし、頂点間は直線でつなぐ。
スプライン補間と違い**カーブが必ず一定半径**になるので、歪んだコーナーができない。

- `fitRadii()` … 隣り合うコーナーの円弧が重なる場合、両方の半径を自動で詰める
- `buildSegs()` … 直線・円弧のセグメント列に展開
- `sampleLoop()` … 全長を等間隔（6px）に打ち直し、各点に接線・法線・**符号付き曲率**を持たせる

曲率が厳密に分かるので、CPU の「曲がりきれる速度」も正確に出せる。

**コース追加**は `COURSES` に1要素足すだけ。ミニマップ・壁・チェックポイントは自動生成。
頂点は**進行方向に並べ、最後の頂点→先頭の頂点が長いストレートになるように**書くと、
そのストレートにスタート／フィニッシュラインが乗る。

設計時の目安（外すと `fitRadii()` の自動縮小でコーナーが潰れる）:
- 最小コーナー半径 ≧ `壁までの半幅 + 21px`
- 別々の区間どうしの中心線間隔 ≧ `壁までの幅 + 20px`
- 頂点は画面端から `壁までの半幅 + 35px` 以上内側に

路面を広げるとこの3条件がすべて厳しくなるため、置けるコーナー数は減る。
Uターンは1頂点の鋭いV字ではなく、**90度コーナー2つ＋2r以上の直線**で作ると収まりやすい。

### 路面の3段階
中心線からの横位置 `off`（法線方向の内積）で判定する。

| 範囲 | 状態 |
|---|---|
| `\|off\| ≦ width/2` | アスファルト。通常走行 |
| `width/2` を越える | 縁石ラインに接触。ドラッグ増＋グリップ低下で減速、砂ぼこり |
| `\|off\| > 壁までの半幅 − 車半径` | 壁。位置を戻して法線速度を反発、火花と画面揺れ |

低速時でもアクセルを踏んでいれば舵が効くようにしてある
（これが無いと壁に鼻から刺さったまま脱出できなくなる）。壁に直角にぶつけても約1.2秒で復帰できる。

### そのほか
- **表示**：ワールドは常に 1280×720（16:9）。ウィンドウに合わせて最大化して中央に置き、
  地面はウィンドウ全体に敷き詰める。コース画像は表示倍率に合わせて描き直す。
  16:9 のウィンドウなら余白なしで画面いっぱいになる
- **物理**：速度ベクトル + 車体角。横方向速度をグリップ分だけ吸収（残りがドリフト感）
- **車の向き**：前は尖ったノーズ＋ヘッドライト＋前向き矢印、後ろは幅広の黒いウイング＋
  テールランプ＋太いタイヤ。回転しても前後が分かるようにしている
- **エンジン音**：Web Audio でプレイヤー1人につき1基。のこぎり波＋矩形波をローパスに通し、
  速度から擬似的に5速ぶんのシフトを作って音程・音量・カットオフを動かしている。
  `M` でミュート。ラップ音・壁の衝突音も同じ AudioContext を使う
- **周回判定**：コースを 12 のチェックポイントに分割し、**順番に一周ぶん通過して初めて**
  1ラップ成立。スタート直後の押し合いでラインをまたいでも誤カウントしない
- **CPU**：先読み点へ向かう P 制御 ＋ コーナー内側へのライン取り。
  先の最小旋回半径 R から `PHYS.turn * R` を上限速度としてアクセルを調整する。
  `skill` で個体差、`lane` で走行ラインの癖をつけている
